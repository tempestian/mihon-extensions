# Tempestian TR Extensions for Mihon

Mihon ve uyumlu manga okuyucuları için güncel, optimize edilmiş ve bakımı yapılan Türkçe eklenti deposu.

## 📱 Mihon'a Nasıl Eklenir?

1. Mihon uygulamasını açın.
2. **Daha Fazla** (`More`) -> **Ayarlar** (`Settings`) -> **Göz At** (`Browse`) -> **Eklenti Depoları** (`Extension repositories`) yolunu izleyin.
3. **Depo Ekle** (`Add repository`) butonuna dokunun.
4. Depo URL'si olarak aşağıdaki adresi yapıştırın:
   ```
   https://raw.githubusercontent.com/tempestian/mihon-extensions/repo/index.min.json
   ```

## 🛠️ Özellikler
* Tüm popüler Türkçe manga, manhwa ve webtoon kaynakları tek bir depoda.
* Kapanan veya alan adı değişen Türkçe kaynaklar için düzenli güncellemeler.
* Hızlı ve doğrudan bağlantılar.
